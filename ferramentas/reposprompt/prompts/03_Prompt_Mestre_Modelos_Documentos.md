# Prompt mestre — Modelos de documentos

**Uso:** criar documentos profissionais padronizados e reutilizáveis para diferentes situações.

## [PROPÓSITO]

Crie um **modelo de documento** claro, completo, editável e pronto para reutilização. Atue como especialista em documentação e comunicação profissional. O documento deve apresentar uma estrutura adequada à sua finalidade e orientar o preenchimento sem acrescentar dados fictícios como se fossem reais.

## [ ENTRADAS]

Utilize:

- **Tipo de documento:** [relatório, proposta, plano de ação, manual, formulário, ata, parecer, procedimento etc.].
- **Finalidade:** [informar].
- **Público ou destinatário:** [informar].
- **Organização ou projeto:** [informar, se houver].
- **Conteúdo-fonte:** [arquivos, anotações, tabelas, instruções ou referências fornecidas].
- **Seções obrigatórias:** [listar, se houver].
- **Formato de entrega:** [Markdown `.md`, Word `.docx`, PDF `.pdf` ou outro].
- **Padrão visual:** [logotipo, cores, fontes ou template fornecido].

Se algum conteúdo essencial estiver ausente, use um campo identificável como `[PREENCHER]` em vez de supor uma informação.

## [DETALHES]

1. **Estruture o documento:** crie título, identificação, versão/data quando aplicável, objetivo, contexto, conteúdo principal, responsáveis e encerramento conforme a finalidade.
2. **Organize a leitura:** use títulos hierárquicos, parágrafos objetivos, listas, tabelas e campos de preenchimento onde contribuírem para a compreensão.
3. **Padronize os campos:** indique claramente o que deve ser preenchido, incluindo exemplos de formato quando necessário, sem confundir exemplos com dados oficiais.
4. **Preserve a fonte:** mantenha nomes, números, prazos e conclusões fornecidos, sem criar citações, normas ou resultados inexistentes.
5. **Facilite a reutilização:** deixe espaços para atualização, aprovação, histórico de versões e anexos quando pertinentes.
6. **Aplique o design:** priorize legibilidade, margens equilibradas, tabelas não excessivamente largas e consistência tipográfica.

Não adicione seções sem utilidade para o tipo de documento selecionado.

## [FORMATO]

Entregue **o modelo completo** no formato solicitado, com campos editáveis, seções prontas para preenchimento e, quando apropriado, instruções rápidas de uso. Se for Markdown, utilize sintaxe válida (`#`, `##`, listas e tabelas). Se for Word, mantenha estilos de título e texto editáveis.

## [REVISÃO]

Confira a coerência da estrutura, ortografia, padronização, campos obrigatórios, consistência de dados e legibilidade. Verifique se o arquivo abre corretamente quando for possível testá-lo. Informe quais dados permanecem para preenchimento.
