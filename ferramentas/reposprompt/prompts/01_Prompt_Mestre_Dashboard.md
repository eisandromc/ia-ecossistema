# Prompt mestre — Painel de dados

**Uso:** criar painéis de indicadores claros, interativos e baseados em dados verificáveis.

## [PROPÓSITO]

Crie um **dashboard de dados** para acompanhar resultados, identificar tendências e apoiar decisões. Atue como analista de dados e designer de interfaces. Priorize leitura rápida, indicadores relevantes e visualizações que respondam a perguntas reais do público.

## [ENTRADAS]

Use as informações abaixo e os arquivos fornecidos:

- **Tema ou negócio:** [informar].
- **Objetivo do painel:** [qual decisão ou acompanhamento deseja apoiar].
- **Público-alvo:** [gestores, equipe, clientes etc.].
- **Fonte de dados:** [CSV, XLSX, JSON, API, tabela ou dados colados].
- **Indicadores desejados:** [KPIs e respectivas regras de cálculo].
- **Dimensões e filtros:** [período, produto, setor, projeto, cliente etc.].
- **Ferramenta de entrega:** [HTML/CSS/JS, Excel, Power BI ou outra].
- **Identidade visual:** [marca, cores, logotipo ou referência].

Se houver informações ausentes, trabalhe com os dados realmente disponíveis e **identifique as limitações**; não invente valores.

## [DETALHES]

1. **Entenda os dados:** identifique colunas, tipos, períodos, unidades, valores ausentes e possíveis duplicidades. Explique as regras dos cálculos.
2. **Defina a visão executiva:** apresente título, intervalo analisado, KPIs principais, evolução no tempo e comparações relevantes.
3. **Escolha os gráficos:** use linhas para tendências, barras para comparações e tabelas para detalhes. Evite gráficos decorativos e escalas enganosas.
4. **Crie interações úteis:** filtros, busca, ordenação, detalhes e opção de limpar filtros quando a ferramenta permitir.
5. **Organize o design:** layout responsivo, boa hierarquia, números legíveis, cores consistentes, contraste adequado e estados de carregamento/erro/sem dados.
6. **Explique os resultados:** destaque variações e achados fundamentados nos dados, separando fato de interpretação.
7. **Preserve a origem:** apresente período, fonte e definições dos indicadores. Não simule atualizações em tempo real sem uma conexão funcional.

Se a entrega for web, use **HTML, CSS e JavaScript** sem backend por padrão; só adicione frameworks, bibliotecas ou serviços externos quando solicitados ou necessários e identificados.

## [FORMATO]

Entregue:

- Um **painel funcional e editável** na tecnologia indicada.
- Uma descrição curta de cada KPI e de sua fórmula.
- Uma explicação de como importar ou atualizar os dados.
- Instruções para abrir, usar e manter o dashboard.

Se os dados forem insuficientes, entregue a estrutura preparada para recebê-los, com estado vazio claro, em vez de números fictícios apresentados como reais.

## [REVISÃO]

Confirme se os cálculos, filtros e gráficos estão corretos; se os dados exibidos coincidem com a fonte; se a interface funciona em computador e celular; e se títulos, eixos, unidades e legendas são compreensíveis. Identifique o que foi efetivamente testado e o que permanece pendente.
