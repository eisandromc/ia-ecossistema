# Política de segurança

## Escopo

Esta política cobre arquivos e automações mantidos neste repositório, incluindo o painel local, manifestos, prompts, templates e scripts.

## Relato responsável

Não publique vulnerabilidades, credenciais, chaves de API, tokens, dados pessoais ou detalhes exploráveis em issues públicas.

Use o recurso **Report a vulnerability** do GitHub quando estiver disponível neste repositório. Caso contrário, contate o mantenedor pelo perfil GitHub e solicite um canal privado de comunicação.

## Boas práticas

- Mantenha chaves somente em arquivos `.env` locais.
- Use os arquivos `.env.example` ou `.env.exemplo` apenas como modelos, sem valores reais.
- Revise alterações em workflows, dependências e integrações antes do merge.
- Atualize dependências por Pull Request e valide os testes disponíveis.
